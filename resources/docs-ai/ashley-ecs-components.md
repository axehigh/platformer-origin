### `Mappers` (`com.axehigh.platformer.ecs.components.Mappers`)
Central holder of shared `ComponentMapper<T>` instances (one static field per component above: `TRANSFORM`, `TEXTURE`, `ANIMATION`, `MOVEMENT`, `COLLISION`, `PLAYER`, `BUFF`, `BULLET`, `ENEMY_BULLET`, `ENEMY`, `FLYING`, `HIT_FLASH`, `ENEMY_SHOOTER`, `ENEMY_ATTACK`, `DAGGER_PICKUP`, `COIN_PICKUP`, `CRYSTAL_PICKUP`, `POTION_PICKUP`, `CHEST`, `POPPED_ITEM`, `LEVEL_EXIT`, `MOVING_PLATFORM`, `PARTICLE`, `LIGHT`, `TRAP`, `SLASH_ARC`, `TRAIL`, `TUTORIAL`). **Every system must read/write components through these mappers** instead of creating new `ComponentMapper.getFor(...)` calls. Adding a new component requires adding its mapper here.
