## 2. Systems (`com.axehigh.platformer.ecs.systems`)

Each row lists the Ashley base class, the entity `Family` it processes (as configured in its constructor), and its responsibility. "Priority" refers to the value passed in by `GameSystems` (lower runs first); systems are also usable with priority `0` via their no-arg/short constructors for tests or other screens.

### System wiring & priority order (`ecs.GameSystems`)
All gameplay systems are constructed and registered with the `PooledEngine` by the `GameSystems` installer (one instance built in `GameScreen.show()`), not by the screen itself; `GameScreen` keeps handles only on the bundle's exposed members (`playerInputSystem`, `tiledMapRenderSystem`, `debugRenderSystem`, `lightRenderSystem`, `vignetteRenderSystem`, `cameraSystem`, `chestSystem`, `levelManager`). Systems are added to the `PooledEngine` in this priority order (lower runs first each frame); `EnemySystem`/`EnemyShootSystem`/`BuffSystem`/`TrapSystem` share priority `4`, `CrumblingTileSystem`/`MovementSystem` share priority `5` (`CrumblingTileSystem` is added **first** within the tier and Ashley's sort is stable, so a tile collapsed this frame has its rect removed from `oneWayRects` before the player's move is resolved), `CollisionBoundsSystem`/`DespawnSystem`/`MovingPlatformSystem`/`AmbientEmberSystem` share priority `6` (`DespawnSystem` runs after `CollisionBoundsSystem` and `MovingPlatformSystem` is added **after** `DespawnSystem`, and Ashley's sort is stable, so within the tier bounds refresh runs first, then despawn, then platform carry; `AmbientEmberSystem`, registered last in the tier, only spawns particles â€” order-insensitive), `PlayerBulletSystem`/`EnemyBulletCollisionSystem` share priority `7`, and `MeleeAttackSystem`, `SfxSystem`, `PickupSystem`, `ChestSystem`, `EnemyContactSystem`, `EnemyAttackSystem`, `HazardSystem`, `TrapContactSystem`, `LevelExitSystem`, and `PlayerDeathSystem` share priority `8` â€” relative order within each shared tier is not meaningful except for the noted boundsâ†’despawnâ†’platform order and the `EnemySystem` â†’ `EnemyShootSystem` order in tier `4` (`EnemySystem` is added **first** and Ashley's sort is stable, so it runs before `EnemyShootSystem`; that is what makes a shooter's turn-idle stand-still win — `EnemyShootSystem` re-asserts the zeroed velocity after `EnemySystem` has written the patrol velocity, and `MovementSystem` integrates it):
